

## Dokumentasi Kustomisasi

Panduan lengkap untuk mengganti data pasangan, tanggal acara, nama tamu melalui URL, foto, emblem, musik, RSVP, buku tamu, galeri, pembayaran, dan tema visual tersedia di [`CUSTOMIZATION.md`](CUSTOMIZATION.md). Gunakan panduan tersebut sebelum mengubah `client/src/pages/Home.tsx` atau `client/src/index.css`, lalu jalankan `pnpm check` dan `pnpm build` sebelum membuat checkpoint.
